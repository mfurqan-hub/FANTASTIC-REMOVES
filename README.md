# Vanilla HTML/CSS/JS version

This folder contains a **plain HTML/CSS/JS** multi-page version of the site (no React build needed).

## Pages

- `vanilla/index.html`
- `vanilla/services.html`
- `vanilla/how-it-works.html`
- `vanilla/reviews.html`
- `vanilla/faq.html`
- `vanilla/contact.html`
- `vanilla/404.html`

## How to run locally (quick)

Open `vanilla/index.html` in your browser.

Tip: if you use a local web server (recommended), relative navigation works the same but you avoid some browser restrictions.
